# Principekaarten

Leerapp voor gedragsprincipes in donatiefunnels: korte lessen met draaikaarten, vragen en herhaling (1, 2, 4, 8, 16 dagen).

- Installeerbaar op Android via Chrome (PWA), werkt offline.
- Voortgang staat lokaal op het apparaat (localStorage).
- Kaarten aanpassen: de lijst `CARDS` bovenin `main.js`.

## Lokaal draaien
npm install
npm run dev

## Op Vercel
Importeer de repo in Vercel. Framework: Vite. Build: `npm run build`, output: `dist`.
